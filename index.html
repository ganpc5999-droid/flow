FLOW / FIELD NOTES 04

连接，然后即兴。

  1. 在 iPad / iPhone 的 MIDIWeb 中横屏打开。USB 或蓝牙 MIDI 连接 FP-30X 后，点击「连接 MIDI」。
  2. 同时按下几个音，右侧显示和弦。默认只识别当前按键，可切换「含踏板延音」。单音、双音和不明确的组合不会强行判断。
  3. 需要原音频时先启用音频输入。点击「录制」，遇到喜欢的片段点「⚑ 标记」。保持页面前台，切到后台会停止并保存。
  4. 停止后可回听、设置 A–B 循环，或从录音库打开历史演奏。导出分析包可一次带走全部数据。

和弦依据 MIDI 音高集合识别，稳定约 100 毫秒后更新。C6 与 Am7/C 等组合会显示备选，不等于确定的和声功能；含踏板模式不模拟声音衰减。

Program Change / Bank Select 只有在钢琴实际发送时才会记录。真实音色请结合音频与手填名称判断。录音不会自动上传。
