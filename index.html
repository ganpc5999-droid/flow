FLOW / QUICK GUIDE

连接，然后即兴。

  1. 在 iPhone / iPad 的 MIDIWeb 中打开此 HTTPS 网页。USB 连接使用 FP-30X 的 USB COMPUTER 接口及合适转接器。
  2. 蓝牙连接请先在 MIDIWeb 的蓝牙 MIDI 面板中配对 FP-30X。蓝牙音频不能替代蓝牙 MIDI。
  3. 点击「连接 MIDI」，允许访问并选择设备。弹奏后确认力度读数，再点击「录制」。
  4. 停止后导出 MIDI 到音乐软件，或导出 JSON 备份原始事件。延音 CC64 保留完整 0–127 数值。

演奏仅保存在当前浏览器，不上传。录制期间保持页面在前台；新录制会替换上一段，请及时导出。本页不生成钢琴声音。

音色信息：录制期间收到的 Program Change / Bank Select 会保留在原始数据中；不等于实际声音。请随分析材料补充音色名称。

FLOW / AUDIO CAPTURE

记录钢琴的声音。

音频未启用

USB 连接 FP-30X 后启用音频，并检查输入来源。蓝牙 MIDI 不传送钢琴声音；选择 iPad 麦克风录到的是环境声音。

允许音频访问后，与主面板的「录制 / 停止」联动。若系统显示麦克风权限，这是音频输入访问权限。

按录制开始的本地日期时间命名。音频暂存在本页，停止后请及时保存；刷新、关闭或系统回收页面会丢失未保存音频。MIDI 仍独立自动保存。音频和 MIDI 接近同步，但不保证采样级对齐。
