FP-30X / iPhone / iPad 连接说明
  1. 在支持 Web MIDI 的 iOS MIDIWeb 中，通过 HTTPS 打开此页面。若提示浏览器不支持，请换用支持 Web MIDI 的浏览器。
  2. USB 连接：使用适配手机／平板接口的转接器，将 FP-30X 的 USB COMPUTER 接口连接到设备。
  3. 蓝牙 MIDI：先在 MIDIWeb 提供的蓝牙 MIDI 设备面板中配对 FP-30X；蓝牙音频配对不能替代 MIDI 配对。具体可用性取决于浏览器及系统。
  4. 点击“连接 MIDI”并允许访问，在下拉列表选择 FP-30X。弹奏后看到音符和力度变化，即可开始录制。
  5. 延音踏板记录 CC64 的原始 0–127 数值（含设备发送的半踏板值）。分析用 64 作为踩下阈值。断开设备会自动结束录制。
本页不向钢琴发送 MIDI，也不生成钢琴声音。音符时长表示按键持续时间；延音信息独立保留在 MIDI 控制事件中。
